# AI Usage

AI tools were used as development assistance during the implementation of this project.

## AI Tool Used

* ChatGPT

## How AI Was Used

AI assistance was used primarily for development guidance, debugging, code review, and documentation support.

The assistance included:

* Reviewing frontend and backend implementation approaches.
* Helping identify and troubleshoot API integration issues.
* Assisting with React component and REST API implementation patterns.
* Providing suggestions for loading and error handling.
* Helping troubleshoot PostgreSQL and deployment configuration issues.
* Assisting with environment variable and CORS configuration during production deployment.
* Reviewing and improving project documentation.

## Developer Responsibility

All generated suggestions were reviewed and adapted to the project's actual requirements. The application was run and tested locally before deployment, and the production frontend, backend API, database connection, CRUD operations, and inquiry flow were verified after deployment.

AI was used as an assistant rather than as a replacement for implementation and technical decision-making.

## Validation

The final implementation was manually tested for:

* Property listing and property details.
* Property creation, editing, and deletion.
* Inquiry submission.
* API connectivity between the frontend and backend.
* PostgreSQL database connectivity.
* Production deployment using Vercel and Render.

## Limitations

AI-generated suggestions were not accepted blindly. They were reviewed against the existing codebase, corrected when necessary, and validated through local testing and production deployment.
